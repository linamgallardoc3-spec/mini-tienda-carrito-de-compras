## Mini Tienda con Carrito de Compras

# Manipulación del DOM · Eventos · Bootstrap 5

En este laboratorio construirás desde cero una mini tienda en línea con carrito de compras funcional. Usarás HTML para la estructura, Bootstrap para el diseño visual y JavaScript para hacer que todo cobre vida al interactuar con el DOM.
Al finalizar tendrás una página donde el usuario puede agregar productos al carrito, eliminarlos individualmente ver el total actualizado y vaciar el carrito — todo sin recargar la página.
